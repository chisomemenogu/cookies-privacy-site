About This Project

This website was created for the IT 3203 Web Development Project. Milestone 1 asks students to build an information website with HTML and CSS, using research from an earlier assignment as its starting point. The site explores cookies and privacy, covering how cookies work and how privacy laws regulate them.

Later milestones will add a quiz built with JavaScript and make the site responsive for mobile devices.

This website is a class project for IT 3203 Web Development. Visit the class website.
