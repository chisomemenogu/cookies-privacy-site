Cookies and Privacy: How the Web Remembers You

Milestone 1: Basic Website with HTML/CSS

Abstract

HTTP is a stateless protocol, so a web server does not automatically remember who you are between requests. Cookies solve this problem by letting a server store small pieces of data in your browser. Cookies make logins, shopping carts, and personal settings possible, but they are also the main tool advertisers use to track people across websites. This site explains how cookies work, how privacy laws such as the GDPR and the CCPA regulate them, and what changes are coming as browsers limit tracking.

Key Terms

  • Cookie: a small piece of data a server asks the browser to store.
  • First-party cookie: set by the website you are visiting.
  • Third-party cookie: set by a different domain, often an advertiser embedded in the page.
  • Consent banner: the pop-up that asks permission before non-essential cookies are set.
