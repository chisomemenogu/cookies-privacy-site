Key Concepts

Seven essential terms for this topic

Cookie
A small text value that a server asks the browser to store with a Set-Cookie header. The browser returns it in later requests to the same site.
First-party cookie
A cookie set by the domain shown in the address bar. It is used for core site features such as login and preferences.
Third-party cookie
A cookie set by a domain other than the one the user is visiting, usually through an embedded ad or analytics script. It can follow users across many sites.
Session cookie
A cookie without an expiration date. It is normally deleted when the browser session ends.
Persistent cookie
A cookie with an Expires or Max-Age value. It stays on the device until that time passes or it is deleted.
Consent banner
The notice that asks a visitor to accept or reject non-essential cookies. Under the GDPR, a valid banner gives a real choice and does not hide the option to refuse.
Fingerprinting
Identifying a device by combining attributes such as screen size, installed fonts, time zone, and browser version. It does not need to store anything on the device.
